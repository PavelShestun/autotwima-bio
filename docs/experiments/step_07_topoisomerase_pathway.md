# Эксперимент 2.2: Моделирование каталитического пути Topoisomerase II и профиля гель-электрофореза

## 1. Научная гипотеза
Фермент Topoisomerase II осуществляет АТФ-зависимый проход двухцепочечной ДНК сквозь разрыв,
дискретно меняя топологический инвариант узла плазмиды. В мокрой лаборатории этот процесс
детектируется как сдвиг дискретных полос на агарозном гель-электрофорезе.

Мы проверяем, что алгебраический квандл сопряжения из статьи Autotwima (Теорема 7.3)
монотонно описывает переход топоизомеров от сверхскрученного узла к открытому кольцу:
$$\text{Trefoil } (3_1) \xrightarrow{\text{Topo II}} \dots \xrightarrow{\text{Topo II}} \text{Relaxed Unknot } (0_1)$$

## 2. Результаты симуляции пути релаксации
- **Начальное состояние (Knotted Trefoil):**
  - Квандл-инвариант раскрасок: $Q = 9$.
  - Относительная электрофоретическая подвижность: $\mu = 1.000$ (быстро бегущая компактная полоса).
- **Конечное состояние (Relaxed Circle):**
  - Квандл-инвариант раскрасок: $Q = 3$.
  - Относительная электрофоретическая подвижность: $\mu = 0.500$ (медленно бегущая открытая полоса).
- **Монотонность:** $\Delta Q \le 0$ на каждом каталитическом шаге без регресса.
