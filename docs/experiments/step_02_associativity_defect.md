# Эксперимент 1.2: Аналитическое измерение дефекта ассоциативности геномных координат

## 1. Научная гипотеза
В классической геномике конкатенация сегментов неявно считается ассоциативной:
(A * B) * C = A * (B * C).
При наличии инверсий (Structural Variations, минус-нить) возникает координатный сдвиг.
Мы проверяем аналитическую формулу непрерывного/дискретного дефекта (Теорема 5.4 статьи Autotwima):
$$Defect(a, b, c) = ((a \cdot b) \cdot c)_x - (a \cdot (b \cdot c))_x = \varepsilon_2 (1 - \varepsilon_1) x_3$$

## 2. Результаты верификации
1. **Прямая цепь ($\varepsilon_1 = +1$):**
   - $Defect = \varepsilon_2 (1 - 1) x_3 = 0$.
   - Классическая ассоциативность сохраняется.
2. **Инвертированная цепь ($\varepsilon_1 = -1$):**
   - $Defect = 2 \varepsilon_2 x_3 \ne 0$.
   - Фазовый сдвиг строго равен удвоенной длине третьего сегмента с учетом ориентации второго сегмента.
   - Тесты подтвердили 100% сходимость численного дефекта с формулой из доказательства Lean 4.
